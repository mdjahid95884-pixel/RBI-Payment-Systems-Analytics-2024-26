# RBI Payment Systems Analytics 2024–26

## 📊 Project Overview

An end-to-end **Data Analytics & Business Intelligence** project analyzing India's major payment systems from **April 2024 to August 2026**.

The project focuses on **UPI, RTGS, NEFT, and IMPS** transaction volume and transaction value.

## 🛠️ Tools & Technologies

- 🐍 **Python** – Data Cleaning, EDA & Analysis
- 🔄 **Power Query** – Data Transformation & Preparation
- 📊 **Power BI** – Dashboard Development & Data Visualization
- 🧮 **DAX** – KPIs, Measures & Calculations
- 🗄️ **Excel** – Data Analysis & Querying

## 📈 Dashboard Pages

- 🏠 **Home** – Overall payment-system performance
- 🔵 **UPI** – Transaction & amount trends
- 🟢 **RTGS** – Transaction & high-value amount analysis
- 🟡 **NEFT** – Transaction & amount analysis
- 🟠 **IMPS** – Transaction & amount trends
- 📑 **Report** – Overall insights and findings

## 🔍 Key Analysis

- Analyzed **transaction volume and transaction value**
- Compared **UPI, RTGS, NEFT & IMPS**
- Created **Financial Year (FY) analysis**
- Analyzed **monthly and yearly trends**
- Created interactive **KPI cards and dashboards**
- Compared **high-volume vs high-value payment systems**
- Generated business insights from payment-system trends

## 💡 Key Insights

- **UPI** dominates transaction volume.
- **RTGS** handles significantly higher-value transactions with comparatively fewer transactions.
- **IMPS** remains an important instant-payment channel.
- **NEFT** provides an important electronic fund-transfer channel.
- Transaction **volume and transaction value show different patterns** across payment systems.
